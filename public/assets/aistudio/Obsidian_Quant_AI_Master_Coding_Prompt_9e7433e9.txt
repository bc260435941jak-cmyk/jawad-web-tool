IMPORTANT REALITY / SAFETY RULES
- No fake market prices, fake candles, fake news, mock AI responses, fabricated latency, fake connected status or fake broker order confirmations.
- Free API access is limited and can change. Do not promise unlimited or high quotas.
- Never evade rate limits by rotating keys/accounts. Respect provider terms, user entitlements and data licensing.
- Free API data may be delayed, incomplete, limited to certain symbols, or not suitable for commercial redistribution. Display provider, data timestamp, freshness and plan limitations.
- If data is missing/stale/invalid or all APIs are down, show DATA UNAVAILABLE / WAIT. Do not fabricate a signal.
- AI is advisory and must never directly execute an order.
- Paper trading is the default. Real-money trading must be disabled unless an official supported broker adapter, valid user account, explicit consent, risk controls and broker acknowledgement are implemented.
- Do not claim 100% bug-free software. Build in phases, run tests, fix failures, and report remaining limitations honestly.

Build a pluggable MarketDataProvider adapter interface. Candidate free/low-cost providers to investigate and allow user configuration:

- Alpha Vantage (historical FX/indicators; free limits make it unsuitable for high-frequency polling)
- OANDA practice API (demo/practice account, not a universal free market feed)
- Stooq or public historical CSV sources for appropriate historical/backtest use only
- Custom user-added REST/WebSocket provider if validated and permitted

Do not hardcode free quotas. Provider settings must include official documentation/pricing link and current plan note. At setup time, instruct user to verify account entitlements and real-time market coverage. Do not imply every provider supports real-time Forex WebSocket or binary broker prices.

Provider interface:
- testRest()
- testWebSocket()
- getSymbols()
- getCandles(symbol, timeframe, limit)
- subscribe(symbol, callback)

Normalize candles:
{ timestamp: UTC epoch milliseconds, open, high, low, close, volume|null, source, symbol }
Validate finite OHLC and low <= open/close <= high. Never invent volume. Store source and received timestamps. Show stale status. Never silently mix data providers.

FREE AI PROVIDER ROUTER
Create a provider adapter abstraction for:
- Google AI Studio Gemini API
- OpenRouter free model routes (model IDs configurable; :free routes are rate-limited)
- Groq free plan models (model-specific limits)
- Mistral free/experimental access when currently available
- Other OpenAI-compatible providers added by the user

Do not hardcode a model as permanently free. Provider/model availability and quotas change. Show official documentation/rate-limit link and allow user to configure provider/model/API key. Never claim unlimited quota.
Use a backend-only API key. Never put API keys in frontend bundles, localStorage, source control or .env.example.
Respect provider Retry-After. For 429/503, cooldown the provider, reduce request frequency, and optionally use a different provider only if the user configured and authorized it. Do not rotate keys to evade limits. If all providers fail, return AI_UNAVAILABLE; never fake a signal.
AI request includes:
- symbol and timeframe
- market status
- candle history and live price timestamp
- RSI-14, SMA-20, EMA-20, MACD, ATR
- data provider and source timestamp
- compact context and user-selected strategy
Never send provider keys or broker secrets to the model.
Validate output with Zod. Direction allowed: BUY, SELL, WAIT. Status allowed: STRONG, CONDITIONAL, WAIT, REJECTED. Include reasoning, invalidation conditions, risk notes, data timestamp and model ID.
Confidence must be called “model-reported confidence” unless calibrated on out-of-sample data. It is not a win probability. Reject hallucinated price values, malformed output, stale data and missing fields.

BINARY QUANT ENGINE
Features:
- EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, USD/CAD, NZD/USD and provider-supported symbols
- Timeframes 1m, 5m, 15m
- Live candlestick chart and countdown
- SMA20, EMA20, RSI14, MACD, ATR, Bollinger Bands
- AI signal panel with WAIT/CONDITIONAL status and reasoning
- Stake presets $5/$10/$25/$50/$100 and custom amount
- Duration selector
- Payout only when verified from a provider/broker contract
- Paper CALL/UP and PUT/DOWN buttons
- Open paper trades, settlement and history
- Max stake, max open trades and daily-loss controls
Payout formula: win profit = stake * payout rate; total return = stake + win profit; loss = stake. Do not hardcode 95% as universal.
No real binary execution unless a documented, authorized broker API exists and legality/availability is checked for the user’s jurisdiction.

FOREX AI SUITE
- Independent Forex symbols and timeframes 15m, 1h, 4h, 1d
- Chart, bid/ask/spread only if actual provider returns it
- Entry, stop loss, take profit, pip distance, position sizing and risk/reward
- BUY/LONG and SELL/SHORT paper orders by default
- Instrument-specific tick size, pip value, contract size, account currency and precision
- Validate SL/TP direction and broker constraints
Real order execution requires official broker API, user authorization, confirmation, risk checks and broker receipt. Never simulate a successful live order.

LIVE CHART / WEBSOCKET
REST loads historical candles. WebSocket supplies ticks. Validate/deduplicate ticks, aggregate OHLC by candle interval, update chart and indicators. Finalize previous candle when interval changes. Handle late/out-of-order ticks.
States: CONNECTING, CONNECTED, RECONNECTING, STALE, DISCONNECTED, ERROR.
Implement heartbeat, timeout, exponential reconnect, resubscribe, REST resync after reconnect, duplicate detection, bounded retry and last-update timestamp.
Vercel serverless connections may close; do not rely on in-memory state or immortal function processes. Use managed persistent worker/pub-sub when necessary.

BACKTEST ENGINE
- Historical symbol/timeframe/date range
- strategy and indicator parameters
- entry/exit, SL/TP, binary expiry, spread/fees/slippage
- no look-ahead bias or future leakage
- data integrity checks and missing candle detection
- out-of-sample and walk-forward tests
- metrics: total trades, win rate, net P/L, profit factor, max drawdown, expectancy, average win/loss and streaks
- trade-by-trade report, equity curve and CSV export
Label as historical simulation, not a promise of future profitability.
